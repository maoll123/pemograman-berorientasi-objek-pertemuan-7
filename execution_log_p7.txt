| FASE 1: AUDIT & PEMBUKTIAN LARANGAN INSTANSIASI ABSTRACT CLASS               |
+------------------------------------------------------------------------------+
  Pada Modul 7, superclass Kendaraan dan Person dideklarasikan sebagai 'abstract'.
  Artinya, kode berikut TIDAK BOLEH dikompilasi oleh Java Compiler:
    // Kendaraan k = new Kendaraan(...); // COMPILE ERROR: Kendaraan is abstract
    // Person p = new Person(...);       // COMPILE ERROR: Person is abstract
  [VERIFIKASI DESAIN] Abstraction menjamin entitas umum tidak dapat diinstansiasi langsung.
  Hanya subclass konkrit yang dapat diinstansiasi di Heap Memory.
